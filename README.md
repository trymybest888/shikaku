# Shikaku สำหรับ Windows

เปิด `Shikaku.exe` เพื่อเล่นโดยไม่ต้องติดตั้งเกม ไม่ใช้เบราว์เซอร์และไม่ต้องเชื่อมต่ออินเทอร์เน็ต ต้องมี .NET Framework 4.5 ขึ้นไป ซึ่งมีตามปกติใน Windows 10/11 โปรแกรมเปิดได้ครั้งละหนึ่งหน้าต่างต่อผู้ใช้ เพื่อป้องกันเกมค้างและสถิติทับกัน

## การเล่น

เลือก Easy 5×5, Medium 10×10, Hard 20×20, Expert 30×30 หรือ Master 40×40 แล้วลากเมาส์สร้างสี่เหลี่ยม แต่ละรูปต้องมีตัวเลขหนึ่งตัวและจำนวนช่องตรงกับตัวเลข แตะรูปเดิมเพื่อลบ ลากทับเพื่อแทนที่ หรือกดย้อนกลับ เมื่อเหลือสี่เหลี่ยมสุดท้ายที่ถูกต้อง เกมเติมให้และประกาศชนะอัตโนมัติ

มีตรวจคำตอบ เสียงวางช่อง ซูมกระดาน และเต็มจอเฉพาะกระดาน กด Esc เพื่อออกจากเต็มจอ

โจทย์ใหม่ตรวจการครอบคลุมทุกช่องและจำนวนคำตอบก่อนแสดง ต้องมีคำตอบเดียว หากพบหลายคำตอบหรือการค้นหาหมดเวลา จะปรับโจทย์และตรวจใหม่ ไม่ยอมรับผลที่ยังพิสูจน์ไม่ได้ สร้างโจทย์เบื้องหลังโดยหน้าต่างยังตอบสนอง จำกัดการตรวจแต่ละรอบและการปรับโจทย์ประมาณ 2.5 วินาทีต่อชุด หากยังพิสูจน์ไม่ได้จะสุ่มชุดใหม่ ไม่ใช้แถวซ้ำเป็นโจทย์สำรอง โดยย้ายตำแหน่งตัวเลขหรือแบ่งสี่เหลี่ยมเป็นรูปที่มีอย่างน้อย 2 ช่อง โจทย์ทุกระดับไม่มีเลข 1

## บันทึกเกมและป้องกันกระดานหาย

เกมบันทึกหลังเปลี่ยนรูปที่วาง ย้อนกลับ ตรวจคำตอบ เปลี่ยนการซูมหรือเสียง รวมทั้งทุก 10 วินาทีและก่อนปิด เปิดใหม่จะกลับมากระดานเดิมพร้อมรูปที่วาง ประวัติย้อนกลับ เวลา รหัสกระดาน และการตั้งค่า เวลาที่ปิดโปรแกรมไม่ถูกนับเป็นเวลาเล่น

หากมีกระดานกำลังเล่น จะถามยืนยันก่อนเริ่มใหม่หรือเปลี่ยนระดับ การล้างกระดานถามยืนยันและย้อนกลับได้ หากบันทึกก่อนปิดไม่สำเร็จ เกมแจ้งให้เลือกกลับไปแก้ไขหรือยอมปิดและทิ้งการเปลี่ยนแปลง

ไฟล์อยู่ใน `%LOCALAPPDATA%\Shikaku\session.xml` พร้อมสำรอง `.bak`

## Achievement / EXP / Level

หน้า Achievement แสดงจำนวนกระดานที่ชนะต่อระดับ EXP รวม และภาพยศ ปรับขนาดตามจอ รองรับ DPI และเลื่อนเนื้อหาได้บนจอเล็ก โดยปุ่มกลับไปเล่นอยู่ด้านล่างเสมอ

- Easy: 25 EXP
- Medium: 100 EXP
- Hard: 400 EXP
- Expert: 900 EXP
- Master: 1,600 EXP

ทุก 1,000 EXP เพิ่ม 1 Level เริ่ม Level 1 ที่ 0 EXP: Level 1–5 มือใหม่, 6–10 ผู้ชำนาญ, 11–20 มืออาชีพ, 21 ขึ้นไป เทพเจ้า

สถิติอยู่ใน `%LOCALAPPDATA%\Shikaku\progress.xml` พร้อมสำรอง `.bak` ก่อนเพิ่มรางวัลจะล็อกไฟล์และอ่านสถิติล่าสุด จึงไม่เขียนทับชัยชนะจากข้อมูลในหน่วยความจำที่เก่าแล้ว

กระดานเดียวรับรางวัลได้ครั้งเดียวแม้เปิดใหม่หรือเล่นให้ชนะซ้ำ รางวัลที่บันทึกไม่สำเร็จถูกเก็บเป็นคิวในไฟล์เกมค้าง ไม่หายเมื่อเริ่มกระดานใหม่ กด **ลองบันทึกใหม่** เพื่อส่งรางวัลค้าง และระบบลองให้อีกครั้งเมื่อเปิดเกม

## ไฟล์และการพัฒนาต่อ

- `Shikaku.exe`: โปรแกรมพร้อมเล่น ภาพยศฝังอยู่ภายใน ย้ายไฟล์เดียวไปเล่นบนเครื่องอื่นได้ (สถิติและเกมค้างเก็บแยกตามผู้ใช้/เครื่อง)
- `desktop/Program.cs`: หน้าต่าง กระดาน กติกา เสียง และการเชื่อมระบบบันทึก
- `desktop/PlayerProgress.cs`: สถิติ EXP, Level และการบันทึกแบบล็อกไฟล์
- `desktop/SessionStore.cs`: เกมค้าง ประวัติย้อนกลับ และคิวรางวัล
- `desktop/UniquePuzzle.cs`: ตรวจจำนวนคำตอบและปรับโจทย์ให้มีคำตอบเดียว
- `desktop/app.manifest`: รองรับ DPI และธีม Windows
- `assets/ranks/`: ภาพยศและพรอมป์ต์ที่ใช้สร้างภาพ
- `build-desktop.ps1`: สร้างโปรแกรม
- `tests/Regression.cs` และ `tests/run-tests.ps1`: ทดสอบระบบที่เปลี่ยนไป โดยใช้ข้อมูลทดสอบแยกจากสถิติจริง

ปิดเกมก่อนสร้างโปรแกรมใหม่:

```powershell
powershell -ExecutionPolicy Bypass -File .\build-desktop.ps1
```

รันทดสอบ:

```powershell
powershell -ExecutionPolicy Bypass -File .\tests\run-tests.ps1
```

## ผลการปรับปรุงตามรายการทบทวน

แก้ครบทั้ง 6 ข้อ: ป้องกันหลายหน้าต่าง/สถิติทับกัน, บันทึกกระดานค้าง, หน้าสถิติสำหรับจอเล็กและ DPI, คิวรางวัลพร้อมลองบันทึกใหม่, ยืนยันก่อนทิ้งกระดาน และตรวจโจทย์ให้มีคำตอบเดียว

ทดสอบโจทย์คำตอบเดียว 25 กระดานครบ 5 ขนาด รวมทั้งโจทย์ที่มีหลายคำตอบและไม่มีคำตอบ ทดสอบการกู้คืนเกม/เวลา/การตั้งค่า/ประวัติย้อนกลับ, สถิติจากข้อมูลเก่าสองชุด, การให้ EXP ไม่ซ้ำ, ไฟล์ถูกล็อกแล้วลองใหม่, รางวัลค้างข้ามเกมใหม่, กู้ไฟล์สำรอง และหน้าสถิติที่ขนาด 480×360 พร้อมเข้า–ออกเต็มจอ

ทดสอบเพิ่มเติมสำหรับ Master: การกดเริ่มเกมคืนการควบคุมให้หน้าต่างทันที รับเหตุการณ์หน้าต่างระหว่างสร้างโจทย์ และตรวจว่า Master มีคำตอบเดียวพร้อมรูปทรงหลายแบบ


แก้โจทย์ Master แบบแถวซ้ำ: ใช้การตรวจตัวเลขด้วยตารางผลรวมและค้นหาช่องที่มีตัวเลือกน้อยที่สุด ตรวจรูปทรงผสมและห้ามตัวเลข 1 ทุกระดับ กระดาน Master แบบเก่าที่ยังไม่เริ่มเล่นจะสร้างใหม่ให้เมื่อเปิดโปรแกรม


ทดสอบเพิ่มเติม: กระดานใหม่ทั้ง 25 กระดานครบทุกระดับไม่มีเลข 1 และมีคำตอบเดียว เกมค้างจากรุ่นเก่าที่มีเลข 1 จะเสนอสร้างใหม่ในระดับเดิมเมื่อเปิดโปรแกรม (หากเริ่มเล่นแล้วจะถามยืนยันก่อนแทนที่)
