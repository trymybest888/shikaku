# Shikaku

[![Build and test](https://github.com/trymybest888/shikaku/actions/workflows/build.yml/badge.svg)](https://github.com/trymybest888/shikaku/actions/workflows/build.yml)

เกมปริศนา **Shikaku** (แบ่งสี่เหลี่ยม) สำหรับ Windows — โปรแกรมไฟล์เดียว ไม่ต้องติดตั้ง ไม่ใช้เบราว์เซอร์ และเล่นได้โดยไม่ต้องต่ออินเทอร์เน็ต

## ดาวน์โหลดและเล่น

1. ดาวน์โหลด `Shikaku.exe` จากหน้า [Releases](https://github.com/trymybest888/shikaku/releases) (หรือ[สร้างเอง](#สร้างจากซอร์สโค้ด))
2. ดับเบิลคลิกเพื่อเปิดเกม

**ความต้องการของระบบ:** Windows 10/11 ที่มี .NET Framework 4.5 ขึ้นไป (มีมากับ Windows อยู่แล้ว)

> Windows SmartScreen อาจเตือนเพราะโปรแกรมไม่มีลายเซ็นดิจิทัล ให้กด **More info → Run anyway**

## วิธีเล่น

เลือกระดับ แล้วลากเมาส์บนกระดานเพื่อสร้างสี่เหลี่ยม เป้าหมายคือแบ่งกระดานทั้งหมดเป็นสี่เหลี่ยม โดยแต่ละรูปต้อง

- มีตัวเลข **หนึ่งตัวพอดี**
- มีจำนวนช่องเท่ากับตัวเลขนั้น

| ระดับ  | ขนาดกระดาน | EXP ต่อชัยชนะ |
| ------ | ---------- | ------------: |
| Easy   | 5×5        | 25            |
| Medium | 10×10      | 100           |
| Hard   | 20×20      | 400           |
| Expert | 30×30      | 900           |
| Master | 40×40      | 1,600         |

**การควบคุม**

- ลากเมาส์ — วาดสี่เหลี่ยม (ลากทับรูปเดิมเพื่อแทนที่)
- คลิกรูปที่วางแล้ว — ลบ
- ปุ่มย้อนกลับ / ล้างกระดาน / ตรวจคำตอบ / เสียง / ซูม / เต็มจอ
- `Esc` — ออกจากโหมดเต็มจอ

เมื่อเหลือสี่เหลี่ยมสุดท้ายที่ถูกต้อง เกมจะเติมให้และประกาศชนะอัตโนมัติ

## ฟีเจอร์

- **โจทย์มีคำตอบเดียวเสมอ** — ทุกโจทย์ถูกตรวจว่าครอบคลุมทุกช่องและมีคำตอบเดียว ถ้าพบหลายคำตอบจะปรับโจทย์ (ย้ายตัวเลขหรือแบ่งรูป) แล้วตรวจใหม่ ไม่มีเลข 1 ในทุกระดับ และสร้างโจทย์เบื้องหลังโดยหน้าต่างยังตอบสนอง
- **บันทึกอัตโนมัติ** — บันทึกทุกครั้งที่เปลี่ยนกระดาน ทุก 10 วินาที และก่อนปิด เปิดใหม่จะได้กระดาน ประวัติย้อนกลับ เวลา และการตั้งค่าเดิม (ไม่นับเวลาที่ปิดโปรแกรม)
- **ป้องกันข้อมูลหาย** — ถามยืนยันก่อนเริ่มใหม่/เปลี่ยนระดับ/ล้างกระดาน เปิดได้ครั้งละหนึ่งหน้าต่างเพื่อป้องกันสถิติทับกัน และเก็บไฟล์สำรอง `.bak`
- **Achievement / EXP / Level** — ทุก 1,000 EXP เพิ่ม 1 Level (เริ่ม Level 1)

  | Level | ยศ          |
  | ----- | ----------- |
  | 1–5   | มือใหม่     |
  | 6–10  | ผู้ชำนาญ    |
  | 11–20 | มืออาชีพ    |
  | 21+   | เทพเจ้า     |

  กระดานหนึ่งรับรางวัลได้ครั้งเดียว หากบันทึกรางวัลไม่สำเร็จจะเก็บเป็นคิวไว้ และลองใหม่ได้ด้วยปุ่ม **ลองบันทึกใหม่** หรือเมื่อเปิดเกมครั้งถัดไป
- รองรับ High-DPI และจอเล็ก

## ที่เก็บข้อมูล

ข้อมูลเก็บแยกตามผู้ใช้ในเครื่อง ย้าย `Shikaku.exe` ไปเครื่องอื่นได้โดยไม่ติดข้อมูลไปด้วย

| ไฟล์                                   | เนื้อหา                                   |
| -------------------------------------- | ----------------------------------------- |
| `%LOCALAPPDATA%\Shikaku\session.xml`   | เกมที่เล่นค้าง ประวัติย้อนกลับ คิวรางวัล |
| `%LOCALAPPDATA%\Shikaku\progress.xml`  | สถิติ EXP และ Level                       |

ทั้งสองไฟล์มีสำรอง `.bak` — ลบโฟลเดอร์นี้หากต้องการรีเซ็ตทุกอย่าง

## สร้างจากซอร์สโค้ด

ใช้คอมไพเลอร์ C# (`csc.exe`) ที่มากับ .NET Framework 4.x บน Windows — ไม่ต้องติดตั้ง Visual Studio หรือ .NET SDK

```powershell
git clone https://github.com/trymybest888/shikaku.git
cd shikaku
powershell -ExecutionPolicy Bypass -File .\build-desktop.ps1
```

ได้ไฟล์ `Shikaku.exe` ที่โฟลเดอร์หลัก (ภาพยศฝังอยู่ในโปรแกรม) — ปิดเกมก่อนสร้างใหม่ทุกครั้ง

### รันทดสอบ

```powershell
powershell -ExecutionPolicy Bypass -File .\tests\run-tests.ps1
```

การทดสอบใช้โฟลเดอร์ข้อมูลชั่วคราว ไม่กระทบสถิติจริง ครอบคลุม: โจทย์คำตอบเดียวทุกขนาด, การบันทึก/กู้คืนเกม, EXP ไม่ซ้ำ, ไฟล์ถูกล็อก, คิวรางวัล, ไฟล์สำรอง และหน้า Achievement บนจอเล็ก

### ออกเวอร์ชันใหม่

GitHub Actions จะรันทดสอบและสร้าง `Shikaku.exe` ทุกครั้งที่ push เมื่อ push tag ที่ขึ้นต้นด้วย `v` จะสร้าง Release พร้อมแนบไฟล์ให้อัตโนมัติ

```powershell
git tag v1.0.0
git push origin v1.0.0
```

## โครงสร้างโปรเจกต์

```
desktop/
  Program.cs          หน้าต่าง กระดาน กติกา เสียง และการเชื่อมระบบบันทึก
  PlayerProgress.cs   สถิติ EXP / Level และการบันทึกแบบล็อกไฟล์
  SessionStore.cs     เกมค้าง ประวัติย้อนกลับ และคิวรางวัล
  UniquePuzzle.cs     ตรวจจำนวนคำตอบและปรับโจทย์ให้มีคำตอบเดียว
  app.manifest        รองรับ DPI และธีม Windows
assets/ranks/         ภาพยศ และพรอมป์ต์ที่ใช้สร้างภาพ (prompts.md)
tests/                ชุดทดสอบ regression
build-desktop.ps1     สคริปต์สร้างโปรแกรม
```
